Welcome to the official repository for Termux Banner customization script!

## 🛠️ How to Install and Run Banner in Termux

Copy and paste the following commands into your Termux app:

```bash
# Update packages
pkg update && pkg upgrade -y

# Install git and python
pkg install git python -y

# Clone repository
git clone [https://github.com/romilama2/Termux-Custom-Banner.git](https://github.com/romilama2/Termux-Custom-Banner.git)

# Navigate to folder
cd Termux-Custom-Banner

# Run banner script
bash banner.sh

⚠️ Disclaimer: This script is created for educational and terminal customization purposes only.
